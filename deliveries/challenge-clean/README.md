# Entrega mínima reproducible

Entregar **[challenge.zip](challenge.zip)**. La carpeta [challenge/](challenge/README.md)
contiene exactamente los mismos archivos para inspección antes de comprimir.

El paquete reúne informe PDF, código y pruebas, tareas, SFT/DPO y respuestas
finales necesarias para reproducir datos y métricas. Usa nombres funcionales
sin versiones en sus carpetas y no incluye logs ni historial experimental.

El paquete anterior de `deliveries/challenge/` y su ZIP se conservan intactos.
