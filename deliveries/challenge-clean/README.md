# Entrega mínima del desafío

Entregar **[challenge.zip](challenge.zip)**. La carpeta [challenge/](challenge/README.md)
contiene exactamente los mismos archivos para inspección antes de comprimir.

El paquete reúne informe PDF, código y pruebas, tareas y datos SFT/DPO. Las
guías permiten usar el entorno, regenerar tareas y verificar los datos derivados.
Las métricas se presentan en el informe; las corridas originales quedan como
respaldo en el repositorio, sin incluirse en el ZIP.

El paquete anterior de `deliveries/challenge/` y su ZIP se conservan intactos.
