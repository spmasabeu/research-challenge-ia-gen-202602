# Entrega mínima del desafío

Entregar **[challenge.zip](challenge.zip)**. La carpeta [challenge/](challenge/README.md)
contiene exactamente los mismos archivos para inspección antes de comprimir.

El paquete reúne informe PDF, código y pruebas, tareas y datos SFT/DPO. Las
guías permiten usar el entorno, regenerar tareas y verificar los datos derivados.
Las métricas se presentan en el informe. Todas las rutas de uso apuntan a los
archivos del ZIP. Para consultar iteraciones y resultados completos, el README
incluido ofrece el enlace general del repositorio y cómo solicitar acceso al equipo.

El paquete anterior de `deliveries/challenge/` y su ZIP se conservan; ambos
usan la misma definición de modelo generador, con sus informes actualizados.
