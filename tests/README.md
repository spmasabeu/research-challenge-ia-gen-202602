# Pruebas pendientes

- Generador: factibilidad, semilla reproducible y ausencia de duplicados entre splits.
- Verificador: soluciones válidas equivalentes e inválidas por cada restricción.
- Ataques: múltiples respuestas, contradicciones, formatos ambiguos y salidas enormes.
- Evaluación: pass@1/pass@k sobre resultados pequeños calculados a mano.

Todavía no hay pruebas funcionales: los módulos son una estructura inicial.
